Welcome to FUNCTIONAL PROFILES documentation!
==============================================

**Building functional profile embeddings to feed sparsity-based methods
for single-cell and bulk transcriptomics.**

These pages walk through the full pipeline — from obtaining and annotating
proteomes or genomes with KEGG / KOfam / eggNOG, through sparse dictionary
learning and deconvolution, to network analysis and mathematical foundations.
